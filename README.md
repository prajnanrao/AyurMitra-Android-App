# 🌿 AyurMitra – Ancient Wisdom, Modern Wellness

AyurMitra is an Android-based Ayurvedic wellness application developed as part of our Mobile App Development course project.

The application combines traditional Ayurvedic concepts with modern Android technologies to provide users with personalized wellness guidance, health tracking, and educational support.

---

## ✨ Features

- Health Assessment & Wellness Score
- Dosha Detection (Vata, Pitta, Kapha)
- Ayurvedic Herbs Information
- Yoga Guidance & Learning
- Meditation Timer
- Wellness History Tracking
- Expert Consultation Support
- Educational Video Integration
- Firebase Cloud Sync

---

## 📱 Technologies Used

- Java
- XML
- Android Studio
- Firebase Authentication
- Firebase Realtime Database
- Room Database (SQLite)
- Retrofit API Integration
- RecyclerView & Material Design 3
- Glide Library
